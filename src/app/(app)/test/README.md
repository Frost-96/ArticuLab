# Server Actions 测试页面

## 📖 使用说明

本测试页面用于测试 ArticuLab 项目中的 Server Actions 功能，包括认证、场景、用户和写作模块。

## 🚀 访问方式

1. 启动开发服务器：

```bash
npm run dev
```

2. 在浏览器中访问：

```
http://localhost:3000/test
```

## 🧪 测试模块

### 1. 认证模块 (Auth)

#### 功能列表：

- ✅ **用户注册** - 创建新用户账号
- ✅ **用户登录** - 使用已有账号登录
- ✅ **退出登录** - 清除当前会话

#### 测试步骤：

1. 使用"用户注册"表单创建一个新账号（邮箱会自动生成唯一值）
2. 使用"用户登录"表单登录该账号
3. 点击"退出登录"清除会话

### 2. 场景模块 (Scenario)

#### 功能列表：

- ✅ **获取口语场景类型** - 查看所有可用的口语练习类型
- ✅ **获取写作场景类型** - 查看所有可用的写作练习类型
- ✅ **获取场景列表** - 根据筛选条件获取场景列表

#### 测试步骤：

1. 点击"获取类型列表"按钮查看场景类型
2. 输入筛选条件后点击"获取列表"

### 3. 用户模块 (User)

#### 功能列表：

- ✅ **获取用户信息** - 查看当前登录用户的详细资料
- ✅ **修改密码** - 更新账户密码
- ✅ **更新用户资料** - 修改姓名、英语水平、学习目标等

#### 测试步骤：

1. 先登录后才能访问用户模块功能
2. 点击"获取用户信息"查看当前用户资料
3. 填写表单后点击相应按钮更新信息

### 4. 写作模块 (Writing)

#### 功能列表：

- ✅ **创建写作练习** - 创建新的写作任务
- ✅ **获取写作历史** - 查看历史写作记录（分页）
- ✅ **获取练习详情** - 查看特定练习的详细信息
- ✅ **删除练习** - 删除指定的写作练习
- ✅ **保存草稿** - 保存写作草稿
- ✅ **获取草稿** - 读取已保存的草稿
- ✅ **提交批改** - 提交内容进行 AI 批改
- ✅ **获取批改结果** - 查看 AI 批改结果

#### 测试流程：

1. **创建练习** → 填写场景类型等信息，点击"创建练习"
2. **保存草稿** → 复制生成的练习ID，填写内容后保存
3. **获取草稿** → 验证草稿是否成功保存
4. **提交批改** → 填写完整内容后提交给 AI
5. **获取结果** → 查看 AI 批改结果
6. **查看历史** → 查看所有历史记录
7. **删除练习** → 测试删除功能（谨慎操作）

## ⚠️ 注意事项

1. **认证依赖**：大部分功能需要先登录才能使用
2. **数据隔离**：所有操作都基于当前登录用户的身份
3. **唯一邮箱**：注册时会自动生成带时间戳的唯一邮箱，避免冲突
4. **删除操作**：删除练习是永久性操作，请谨慎使用
5. **AI 批改**：提交批改需要配置 OpenAI API Key，否则会失败

## 🔍 调试技巧

- 每个操作的结果都会显示在下方的 JSON 格式区域
- 可以展开查看完整的响应数据结构
- 成功响应包含 `success: true` 和 `data` 字段
- 失败响应包含 `success: false` 和 `error` 字段

## 🛠️ 技术实现

- 使用 Next.js Server Actions 直接调用后端逻辑
- 自动处理 Cookie 和 Session 认证
- 使用 shadcn/ui 组件库构建界面
- TypeScript 类型安全保证

## 🐛 常见问题

**Q: 为什么某些操作返回 "Unauthorized"？**
A: 请先确保已经登录，大部分操作需要认证。

**Q: 注册时提示邮箱已存在？**
A: 每次刷新页面会生成新的唯一邮箱，或者手动修改邮箱地址。

**Q: 提交批改失败？**
A: 检查 `.env` 文件中是否正确配置了 `OPENAI_API_KEY`。

**Q: 如何查看详细的错误信息？**
A: 所有操作的返回结果都会显示在页面下方，包含完整的错误信息。
